# Сквозной проект: обработка текстовых данных от алгоритма до Big Data

Репозиторий содержит материалы двух курсовых работ, объединённых общей темой —
**разработкой конвейера предварительной обработки текстовых данных** и его
применением в среде распределённой обработки.

| Курсовая | Дисциплина | Тема | Что демонстрирует |
|----------|------------|------|-------------------|
| №1 | Алгоритмизация и программирование | Разработка алгоритма и программы для очистки и нормализации текстовых данных на Python | Алгоритмы, структуры данных, оценка сложности, тесты |
| №2 | Технологии обработки больших данных | Применение парадигмы MapReduce для распределённой обработки больших текстовых корпусов с использованием Hadoop Streaming | Архитектура Big Data, масштабирование, интерпретация результатов |

**Логика проекта:** в первой работе создаётся инструмент (программа очистки
текста), во второй — этот же инструмент применяется к большим данным через
MapReduce. Такой сквозной подход позволяет проследить полный цикл работы с
данными: от написания кода до распределённой обработки.

## 📌 Задание (что требуется сделать)

### Курсовая №1 — Алгоритмизация и программирование

**Задание.** Разработать алгоритм и программу на языке Python, которые
выполняют предварительную обработку сырого текста:

1. Читают текстовый файл построчно (потоково, не загружая весь файл в память).
2. Удаляют HTML-теги и служебную разметку.
3. Приводят текст к нижнему регистру, удаляют пунктуацию и цифры.
4. Удаляют стоп-слова (русский и английский языки).
5. Выполняют лемматизацию слов (приведение к начальной форме).
6. Считают частотную статистику слов и сохраняют результат в файл.
7. Оценивают алгоритмическую сложность основных этапов (O-нотация) и
   подтверждают её тестами.

**Требования к результату:** работающая программа с CLI-интерфейсом,
юнит-тесты, блок-схемы алгоритмов, отчёт с листингами и оценкой сложности.

### Курсовая №2 — Технологии обработки больших данных

**Задание.** Применить разработанный в КР№1 конвейер обработки текста в
парадигме MapReduce с использованием Hadoop Streaming:

1. Адаптировать логику очистки текста под Mapper (построчная обработка
   входных данных, выдача пар `слово → 1`).
2. Реализовать Reducer, агрегирующий частоты слов.
3. Запустить задачу на большом текстовом корпусе (объём, не помещающийся
   в оперативную память).
4. Провести эксперименты: замерить время обработки при разных объёмах
   данных, сравнить с локальным запуском.
5. Проанализировать результаты и построить графики (время от объёма,
   распределение частот слов).

**Требования к результату:** работающие `mapper.py` и `reducer.py`, скрипт
запуска, логи экспериментов, отчёт с описанием архитектуры Hadoop/MapReduce
и анализом результатов.
